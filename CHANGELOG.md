# Historique des versions

Toutes les modifications importantes de pix-ssg sont documentées ici. Le projet utilise le [versionnement sémantique](https://semver.org/lang/fr/).

## [1.0.1] - 2026-08-29

### Modifié

- publication de pix-ssg sous licence MIT;
- résolution des dépendances Composer garantie pour PHP 8.3.

## [1.0.0] - 2026-08-29

### Ajouté

- générateur de site statique PHP avec layouts, partials, composants, données et plugins;
- catalogue de 23 templates avec documentation et 69 captures responsives;
- catalogue Markdown généré avec commandes d’installation et de désinstallation;
- installation guidée, mise à jour depuis le dépôt officiel et aide centralisée;
- tests Pest et Vitest, ESLint et Prettier.
